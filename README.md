# Study Doomscroll

A phone-installable study feed that turns short notes into a vertical swipe/scroll experience.

## Run It

```sh
npm install
npm run dev
```

Then open the local URL Vite prints.

## Build

```sh
npm run build
npm run preview
```

## What Is Included

- Mobile-first vertical study feed with snap scrolling
- Subject filters, including multiple subjects at once
- Manual subject and card management
- Local progress tracking
- Dark and light themes
- PWA manifest, app icons, and offline service worker

The first version stores data locally in the browser so it works without accounts or a backend.
